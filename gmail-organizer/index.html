Gmail Organizer

A personal, self-hosted inbox organizer for Gmail.

HomePrivacy Policy

Gmail Organizer is a small Python program that its owner runs on their own computer to keep their Gmail inbox tidy. It uses the Gmail API to sort, label and clean up mail. It is not a hosted service, has no servers and no user accounts, and is not offered to the public.

What it does

  • Audits the last 90 days of mail: who sends it, how often it is read, and whether it has been replied to.
  • Labels messages into Action Required, Receipts/Finance, Newsletters/Keep and Automated/Low Priority.
  • Archives low-priority notifications so the inbox stays close to empty.
  • Moves expired promotions to Gmail's Trash, where they stay recoverable for 30 days. It never permanently deletes mail, and it caps how much it does in each run.
  • Recommends unsubscribes for mailing lists that are rarely opened. It only unsubscribes from lists the owner approves, using the list's standard unsubscribe mechanism.
  • Learns from corrections. If a message it cleaned up is moved back to the inbox, it stops cleaning up mail from that sender.

How Google data is handled

All processing happens on the owner's own computer. Message information is stored only in a local database on that computer and is never sent to the developer or to any third party. See the Privacy Policy for details.

Access it requests

Gmail Organizer asks for one Google permission: https://www.googleapis.com/auth/gmail.modify. It needs this to read message headers and labels, apply labels, archive, move messages to Trash, and send unsubscribe emails that the owner has approved. This permission can't permanently delete mail.
